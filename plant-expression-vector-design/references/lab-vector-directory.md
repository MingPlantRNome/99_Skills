# LAB_VECTOR_DIR：每次调用前检查实验室载体库

## 变量与默认值

载体库统一使用变量 `LAB_VECTOR_DIR`。默认值的唯一权威配置为 `templates/lab-library.config.json`，其中包含用户明确要求保存的 Mac 路径；不要在多个脚本重复硬编码，也不修改用户的 shell 启动文件。

解析优先级：本次显式 `--lab-vector-dir` > 本机环境变量 `LAB_VECTOR_DIR` > 配置文件 default_path。显式覆盖或环境变量为空/无效时报告错误，不静默回退。覆盖仅对本次有效；变更长期默认值需用户明确指定。

这是 Mac 的源文件目录，不是云端沙盒或 HPC 权重目录。`LAB_VECTOR_DIR` 与 Evo2 的 `weights_path` 是两个独立参数：前者有用户指定的默认值，后者仍到实际模型任务时再询问。

## 每次调用的前置检查

1. 每次开始任务都重新读取配置、解析变量，并检查用户 Mac 上的真实路径；旧报告只能当历史记录，不能跳过本次探测。
2. 用本机只读能力或标准库脚本检查目录存在、类型、可读和可进入性。只做一次有界目录访问验证，不为路径检查读取质粒文件内容或递归盘点。
3. 登记检查时间、设备/主机、本次 invocation_id、解析来源、路径和状态。未连接用户设备时写 device_unavailable/未执行，不能在云端检查 `/Users/...` 后声称本机目录不存在。
4. 只有 ready 后，才按项目的名称/编号做有界元数据检索，选择相关文件逐项读取。源库只读，项目输出与新构建保存在另外的版本化目录。
5. 路径被覆盖、设备切换、NAS 连接变化或源文件导入前发现访问状态变化时重新检查。不自动挂载 NAS、创建同名空目录、重命名、删除或写入源库。

## 标准库脚本

`scripts/check_lab_vectors.py` 无第三方依赖，应在能够访问该路径的用户 Mac 执行。不能直接把它在云端运行得到的状态当作 Mac 检查结果；也不为运行检查而自动在 Mac 安装 Python。

```bash
# 按默认配置或当前环境变量，进行本次检查并输出 JSON
python3 scripts/check_lab_vectors.py

# 明确指定本次替代目录；这不是更改长期默认值
python3 scripts/check_lab_vectors.py --lab-vector-dir "/本次用户指定的目录"

# 可选：把本次报告保存到源库以外、尚不存在的新文件
python3 scripts/check_lab_vectors.py --out "/项目输出目录/preflight/本次检查.json"
```

使用配置文件里的路径发起本机原生只读检查时，可以采用等价的 `test -d`、`test -r` 和 `test -x`。若这种简化检查无法区分不存在与权限/挂载问题，应标为未确认，不臆断。

脚本检测状态并设置退出码：ready 为 0，其他状态为 2。它不保存上次结果作缓存，不写 `LAB_VECTOR_DIR`，也不创建缺失目录。

## 失败处理

| 状态 | 行为 |
|---|---|
| ready | 允许进入有界库存检索；不等于目标骨架已找到或有完整序列 |
| missing_or_unavailable | 提示路径不存在或挂载暂不可用，请用户确认 NAS/路径；不要自动建目录 |
| not_a_directory | 请求正确目录，不把同名文件当作库 |
| permission_denied | 说明当前读取权限不足，不申请写权限或修改安全设置 |
| io_error | 保留实际错误，说明可能是文件系统/连接问题，不说“没有这个目录” |
| wrong_execution_host | 到用户 Mac 检查；不能把 Linux 沙盒结果当作 Mac 状态 |
| invalid_configuration | 请求修正本次覆盖或配置；不替换为猜测路径 |
| device_unavailable | 本机工具未连接/不可用时由执行代理记录；目录真实存在性未确认 |
| probe_timeout | 调用方的检查操作超时，记录未确认并提示连接/挂载问题；不等于目录不存在 |

失败时可以继续文献、NCBI 和概念结构分析，但库存标“未确认”，不得声称已优先比较现有材料。用户可提供本次替代路径、上传特定文件，或明确允许跳过库存；只有得到该指示后才能以相应限制继续骨架选择。

若配置本身无效而未能解析源路径，脚本仅向 stdout 给诊断，不写入可能误落在源库内的报告文件。NAS 调用的超时由实际执行工具/作业边界处理，不能把未完成探测解释为 missing。

## 交付与隐私

用户授权把默认目录字符串放入此个人技能 ZIP，不等于授权复制整个载体库。技能包不包含目录内容，不自动上传私有质粒文件，不修改任何原始图谱。路径写入配置不等于永久设置 Mac 环境变量，也不保证 NAS 在未来调用时在线。
