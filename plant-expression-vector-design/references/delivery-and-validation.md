# 交付与验收

## 单次报告

使用 `templates/design-report.md`。开头直接说复刻哪篇论文的哪个构建、精确/表达框/重建/部分新设计等级、骨架选择、intron/密码子结论和阻断项。

架构和交付均检查 `references/evidence-driven-review.md`，附本项目 `templates/design-review.tsv` 所列R01–R12审查结果；先解决序列/结构阻断，不以功能尚未知冒充结构失败，也不把计算序列通过当功能保证。

报告须图文并茂，执行 `references/report-visual-style.md`。概念图、证据箭头、分阶段验证与结果判读和真实序列图谱明确分开；包内格式示例图不能直接交付为真实项目结果，图与报告一并打包并核对相对路径。

每份设计报告必须同时执行 `references/report-boundaries.md`：分别写清适用边界、缺点/权衡、不能回答的问题、待优化方向与最小验证路径。正式报告不得保留模板占位，也不得把“未发现缺点”“需要进一步验证”当作完整边界分析。

从头设计或新增表达产物还必须执行 `references/tag-selection.md`，在报告记录标签询问/用户决定、文献推荐矩阵及最终方案；用户不添加时明确写不添加，不能以待填写或默认标签替代。最终标签的来源、位置、潜在影响和功能验证边界须与序列/图谱一致。

新增标签融合还必须执行 `references/fusion-junctions.md`，交付逐组件 source stop 处理、柔性连接肽 DNA/肽段/长度、双侧接头窗口和完整融合翻译。把可计算的读框一致性与连接肽柔性/功能验证分开，不因序列检查通过就宣称功能无影响。

证据划分为直接实验、间接外推、实际计算、待验证假设和缺失。主要论文给标题、作者、期刊/年、DOI/URL、系统、方法、支持实验与限制，不只复述摘要。事实和原始链接写入交付文件，不以泛化参考表替代逐项依据。

模型报告标实际运行或未运行、检查点/版本、权重 fingerprint（可不计算整个大文件哈希时如实注明）、输入与命令、原始输出、QC、可比性和未校准限制。重复推理只能验证数值稳定性，不产生生物学置信区间。

库存报告增加本次 `LAB_VECTOR_DIR` 的解析来源、检查时间、设备和只读检查状态。过去成功、目录当前可读、找到某文件、文件含可靠序列，是四个不同结论；不能相互替代。

## 输出清单

- `construct.gb` 与 `construct.fasta`：同一确定序列，标“计算设计”；不能冒充已测序样品。
- `plasmid_map.svg` 与 `expression_map.svg`：由注释生成的图，含长度、方向及图例。
- `features.tsv` / `sources.tsv` / `qc_report.json`：坐标、来源、检查结果及哈希。
- 项目证据、序列注册与检索日志，复刻差异、构建策略、验证对照，以及必填的边界、缺点/权衡、未解决问题与优化验证计划。
- 实际运行 Evo2 时另附任务清单、原始输出、运行日志和候选比较；未运行不造分数。
- `design-review.tsv`及适用的`sequence_review.json`/`review_flags.tsv`；后者只有序列观察，不是表达或沉默预测。
- 项目图示输入、`figures/`及`figure-index.json`；图片和正文一起交付，不能只留不可见的绘图代码。

完整载体缺序列时只能交付概念草图并标“非比例、坐标未定”。不要把本包示例空 manifest 或测试序列当成真实植物设计。

## 测试边界

本包 tests 验证的是序列拼接、正负链、joined CDS、跨原点、翻译、保护区、导出重读和模型任务准备/结果协议。模拟命令测试不是 Evo2 验证，不宣称已接入用户 HPC。

目录检查的新增测试覆盖变量优先级、错误执行主机、缺失/文件/权限/IO 错误、每次重新探测和只读输出约束。测试用临时目录和模拟系统状态，不把这些测试误报为实验室 NAS 一直在线。

可复现自检：

```bash
python -m pip install -r requirements.txt pytest
python -m pytest tests -q
```

网络查询是否取得准确文献/版本、实际模型 token 对齐、GPU 数值行为和植物表达功能都须在真实任务中另验。源码/依赖变更后重跑测试，并在首次 HPC 调用时执行本模块的 no-change、batch/padding 和输入对应检查。

报告结构测试只验证模板及规则没有遗漏必填项，不评价未来具体报告的科学真实性。交付前仍须逐条人工/代理复核项目证据、限制、可检验终点与阻断项是否一致。
