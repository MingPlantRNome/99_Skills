# 图文报告风格与生成规则

生成或修改设计报告时读取本文件。用户的格式参照是《Task07-AP1发光植物构建.md》：先给一句话核心逻辑，再用系统图、模块图、工作模式图、构建/遗传路线、阶段验证、对照表和结果判读展开。只沿用图文组织，不将样例的物种、基因、模块数量或未经核验的推论设为通用默认。

## 正文结构

按 `templates/design-report.md` 填写：标题和摘要、核心设计思想、总体系统、模块、机制/工作模式、推荐构建、构建与遗传路线、验证流程、观察与对照、结果判读、序列/QC/Evo2、证据、边界、优化和交接。单基因或非代谢项目按需删去不适用图，说明原因；不强凑三模块、代谢通路或杂交路线。

每个模块重复“设计目的、构建结构、图示、功能解释、证据与待验证点”。模块复杂时用子图，不把所有元件挤进总览。正文以短段落和必要表格解释图；不能只交付代码块，也不能用宽表代替图文报告。

首屏先解释复刻对象和状态。若有可靠且获准使用的总览插图，可置于摘要附近；没有时用本项目系统图，不生成仿真实验照片，不复制缺失的本地图片引用。

## 图的语义与外观

- 角色色贯穿全报告：输入/感知用浅蓝 `#cce5ff`，核心执行用浅橙 `#ffd8a8`，输出/检测用浅绿 `#d3f9d8`；辅助/对照用浅灰。风险或阻断点用红色标记，不用红色暗示已证实。
- 每图优先 3–4 个主节点；长机制链拆图。图中标签简短，解释放图注；中文字体可用 Noto Sans CJK SC、PingFang SC、Microsoft YaHei。禁止小字、裁切和重叠。
- 颜色仅表示角色，不能表示证据强度。生物学箭头逐条标“直接证据/间接证据/计算结果/待验证/信息缺失”；图注给支持的实验、物种/组织和来源。直接证据与计算结果用实线，其他关系用虚线；“计算结果”不能写成功能验证。
- 构建或验证的作业顺序可用实线，但必须标“流程顺序”，不能冒充因果证据。同一图的图例解释线型。
- 图注格式：`图 N｜图名。读图结论；线型/角色图例；证据与适用条件；来源及限制。` 外部来源使用实际原始 URL，本地证据用文件名/记录号，不伪造链接。
- 明确区分：概念图“非比例、坐标未定”；注释图“由实际序列/feature 生成，标长度、方向和坐标”。只允许 `vector_tools.py` 等真实注释流程生成序列级图谱；本报告绘图脚本不能绘制或认证真实质粒图。
- 结果判读图用“观察 → 可能解释 → 排除替代解释 → 最小验证”，不能仅凭终点表型宣布整个机制成立。优化路线同样保留证据级别及否决条件。

## 图与正文一起交付

1. 从 `templates/design-report.md` 建立项目报告目录；将 `templates/report-figures.example.json` 复制为项目 `report-figures.json`，逐条改成项目图。`purpose` 改为 `project`，清除示例标签；节点最多四个，较长图拆分。概念图来源可以为空但必须如实标信息缺失；有证据的连线必须填具体依据。
2. 用下列命令生成可编辑 SVG；需要 PNG 时加 `--png`。脚本只支持顺序图与三分支判读图；其他架构可手绘或使用其他本地工具，不要扭曲机制来适配脚本。需要保留 Mermaid 时放在独立 `.mmd` 文件，正文仍嵌图片。
3. 将图放在对应短段落附近，补齐项目图注及原始来源。模块超过一个时逐个重画子图；依实际数据增加状态前后对照、代谢/空间过程或遗传组合图。
4. 检查 Markdown 中所有相对路径；打包整个报告目录并查看实际图片。正式交付前核对图文、manifest、QC、来源和未知项一致，无示例图、占位和缺失图片。交付的是“计算设计”还是“实验验证”必须可见。

```bash
# 在技能目录运行；输出位置改为项目目录，勿覆盖原始材料
python scripts/render_report_figures.py \
  --input /path/to/project/report-figures.json \
  --out /path/to/project/figures

# 仅在沙箱或用户授权的运行环境准备 PNG 依赖
python -m pip install -r requirements-report.txt
python scripts/render_report_figures.py \
  --input /path/to/project/report-figures.json \
  --out /path/to/project/figures --png
```

PNG 转换还需要系统 Cairo 库和支持中文的字体；缺失时说明依赖与输出状态，不自动安装到用户 Mac 或 HPC。SVG 可正常交付时，正文引用改为已生成的 `.svg`，明确 PNG 未生成；不把未渲染的代码当成图片。

包内 `templates/figures/` 只展示格式：全图标“格式示例｜非真实设计”。实际项目必须重新生成，不能将示例线型、标签、来源或分支当作实验结论。`scripts/render_report_figures.py` 同步生成 `figure-index.json` 保存证据文本与实际输出文件，不执行任何外部序列上传。
