# 架构、intron、密码子与构建策略

## 先复刻，再判断必要适配

所有任务先执行 `references/evidence-driven-review.md` 的R01–R12审查。单元件可用不证明组合有效，瞬时读数不能代替稳定应用；配对元件、邻接表达框、组装级别与实际验证层级单独记录，不自动换成文献排名最高的部件。

为每个转录单元登记启动子、5′UTR/leader、intron、CDS（含标签/信号肽/接头）、3′UTR/终止区域、方向与调控依赖。保留原报道独立转录单元、2A、融合或诱导结构；不要把“多基因串联”自动理解为直接连接多个 CDS。

分别说明蛋白编码区、含 intron 的质粒 DNA 和预期成熟 RNA。编码区域 intron 对应的 CDS 应按外显子 join 注释；预测剪接不是实验已验证剪接。

## 从头设计的标签选择

从头设计和部分重建中新增的表达产物，先按 `references/tag-selection.md` 询问是否添加蛋白标签。用户已明确添加/不添加时引用原指示，不重复询问；尚未回答保持 pending，不能静默添加 GFP、表位标签或默认无标签。

用户需要标签后，再结合用途、蛋白/宿主和原始研究结果检索，推荐少量有依据的候选及融合位置、连接方式、风险和对照。使用 `templates/tag-decision.example.json` 记录并写入 manifest 的 tag_decisions；无标签也保留明确的用户决定。复刻保持原标签，新增/移除/替换另存适配版并确认。

## intron 决策

原文有就保留精确位置和版本，原文无就不自行添加，信息缺失标待核验。缺口设计/明确优化时才输出“不添加、保留、建议测试、证据不足”的结论，列目的、位置、候选来源、宿主证据、剪接风险、对照和 RNA/蛋白/功能读数。

植物实验证明 intron 效果受构建背景和宿主影响，不支持任意 intron 普遍增强（[Morello et al., 2011](https://pmc.ncbi.nlm.nih.gov/articles/PMC3003800/)）。

不要承诺固定增幅；RNA 结构/剪接机制实验优先保真，必要改动单独确认。

## 密码子决策

作者使用的实际 DNA 是复刻基线，包括其优化版本。缺失时继续查找，天然版本只能作为明确标注的替代。

对新设计区分保留、局部兼容改造、受约束优化、证据不足。定义宿主、目标、受保护 RNA 区域及改动范围；保存原序列、逐位点差异、蛋白比对和实际算出的指标，不把 CAI、GC 或 Evo2 分数称为功能证明。

首版脚本只自动处理已列出的等长替换；不内置通用“植物最佳密码子表”，不宣称自动实现宿主特异优化。插入/删除或完整 CDS 重写必须建立新注释、重新检查。

## 骨架与策略

首先按 `references/lab-vector-directory.md` 取得本次有效的 `LAB_VECTOR_DIR` 检查结果，再按文件名/构建名做有界检索。缺少本次检查或本机无法访问时不能宣称已检查实验室库存，也不能把旧索引当作现状。

先对比原骨架与库存的实际版本、用途、转化/维持要求、筛选标记、插入区与克隆接口。同版本且兼容时优先库存；不同骨架给适配方案和差异，不能因已有库存就覆盖复刻目标。目录存在不意味着有目标质粒，也不意味着图谱文件含完整可核验序列。

依据真实序列选择酶切连接、同源组装、Golden Gate/MoClo 或 Gateway 等路线，不预设一种通吃。列清片段来源、已拥有/待获取、组装层级、中间体、接口/留下的序列、每步验证和备选路线。

对模块化克隆分别核验工具包版本、当前组装级别的识别位点与保留/去除规则、overhang、选择标记及留下的编码/非编码序列。DNA上的转录终止区域不是CDS的STOP；不得为了过位点检查自动截短leader或终止片段。

检查重复元件、方向、必需辅助模块、终止区域、筛选表达框、适用的 T-DNA 边界、整体长度与接口风险；风险提示不是已经证实发生的缺陷。文献中分层多基因组装的实证不保证每个新设计同样有效（[Weber et al., 2011](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0016765)）。

引物/订购清单仅在最终模板和设计确认后生成，并另作序列检查；首版不声称包含完整引物优化器或实验反应自动配方。
